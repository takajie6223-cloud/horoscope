# ✨ 星座小站 (horoscope)

一个纯前端、零依赖的星座查询小站。无需后端、无需接口，所有数据离线内置，克隆即用。

**在线使用**：<https://takajie6223-cloud.github.io/horoscope/>

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 🔍 星座查询 | 12 星座的日期、元素、守护星、性格、优缺点、幸运档案，点卡片看详情 |
| 🎂 按生日查星座 | 选择出生日期，自动识别所属星座 |
| 💕 星座配对 | 任选两个星座，给出匹配指数（百分制）、配对等级与相处建议，可一键复制分享 |
| 🔮 今日运势 | 爱情 / 事业 / 财运 / 健康四项指数 + 幸运色 + 幸运数字 + 每日建议 |
| 🏆 配对排行 | 你的星座与全部 12 星座的匹配度排行榜 |
| 📖 星座百科 | 四元素、阴阳极性、三方宫（基本 / 固定 / 变动）入门知识 |

其他细节：深色 / 浅色主题切换（自动记忆）、移动端适配、无任何外部依赖。

## 本地使用

直接双击打开 `index.html` 即可；或者起一个静态服务：

```bash
cd 本项目目录
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 目录结构

```
├── index.html            # 单页应用主页面
├── css/style.css         # 样式（深浅双主题）
├── js/data.js            # 12 星座数据 + 78 组配对 + 运势文案库
├── js/fortune.js         # 每日运势算法
└── js/main.js            # 页面交互逻辑
```

## 实现说明

- **配对数据**：按占星通行规则构建——同象星座（火配火、土配土…）与互补元素（火配风、土配水）评分较高，对宫星座有强烈吸引与张力，共享守护星的组合有特殊化学反应；78 组（含同星座）均为手写文案，不是纯随机数。
- **每日运势**：以「日期 + 星座」字符串做哈希种子，用 mulberry32 伪随机生成确定结果。同一天所有人看到相同结果，第二天自动变化，观感接近真实运势产品。
- **配对等级**：≥90 天作之合 · 80-89 心有灵犀 · 70-79 值得经营 · 60-69 需要磨合 · <60 挑战满满。

## 部署到自己的 GitHub

1. Fork 或推送到你自己的仓库
2. 仓库 Settings → Pages → Build and deployment → Branch 选择 **main**、目录 **/ (root)**，保存
3. 之后每次推送 main 分支都会自动发布，访问地址为 `https://<用户名>.github.io/<仓库名>/`
